# Dossier assets/

Mets ici tes images. Le site les cherchera aux chemins suivants :

## Images utilisées (à fournir)

- **`logo.png`** : logo NaviMoov (le bleu+vert avec le N stylisé)
  - Utilisé dans la navbar en haut à gauche
  - Format conseillé : PNG transparent, hauteur 72px minimum
  - Si absent : le texte "NaviMoov" s'affiche à la place (déjà géré par `onerror`)

## Images optionnelles (pour aller plus loin)

Tu peux ajouter et référencer dans `index.html` ou `styles.css` :

- `hero-bg.jpg` : image de fond du hero (mère avec poussette dans le métro par exemple)
- `affiche.png` : ton affiche format paysage pour une section dédiée
- `team-photo.jpg` : photo de l'équipe au lycée
- `prototype.jpg` : photo du prototype physique

## Tes images uploadées dans le chat
